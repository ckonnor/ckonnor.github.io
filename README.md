# Chance Konnor Portfolio

Personal GitHub Pages site for [ckonnor.github.io](https://ckonnor.github.io/).

This rebuild is intentionally static:

- `index.html` contains the site content.
- `styles.css` contains the full visual system.
- `site.js` contains the small sticky-header interaction.
- `assets/` contains optimized local images used by the page.

The site is published from the `gh-pages` branch.
